# Four-motors
Four DC Motors Using L293D

Project Description

This project controls four DC motors using two L293D motor driver ICs and an Arduino Uno.

The system performs the following sequence:

* Forward movement for 30 seconds.
* Backward movement for 60 seconds.
* Alternating right and left turns for 60 seconds.
* Stops after completing the sequence.

Components

* Arduino Uno
* 2 × L293D Motor Driver
* 4 × DC Motors
* Breadboard
* Jumper wires

2. Backward: 60 seconds
3. Right and left alternately: 60 seconds
